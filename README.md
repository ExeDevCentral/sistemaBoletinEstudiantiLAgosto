## 🎓 Highlights & Features

- **Subject Grade Aggregation:** Automated calculations for semester exams, assignments, and practical labs.
- **Attendance & Conduct Verification:** Comprehensive status badges factoring in minimum requirement compliance.
- **Accessible & Responsive Architecture:** Clean CSS variable system supporting dark and light classroom modes.
- **Export & Print Ready:** Print-optimized CSS styling enabling instant physical report card generation.
